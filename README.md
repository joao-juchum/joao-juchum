## 🚀 Selected Work

### ASIC Physical Design

I'm currently developing and studying complete RTL-to-GDSII flows using both commercial and open-source EDA environments.

Some of my recent work includes:

- RTL-to-GDSII implementation and QoR comparison using Synopsys Design Compiler, ICC2, and Fusion Compiler with the SAED32 technology
- Multi-corner/PVT physical implementation and timing analysis
- TCL automation for implementation flows, reporting, and design analysis
- Development of a Synopsys-compatible physical design environment for the open-source GF180MCU PDK

### Open-Source RTL-to-GDSII Flow

As part of IEEE CASS UFCG, I developed a reproducible educational RTL-to-GDSII flow using:

`Verilog → Yosys → OpenROAD/OpenLane → SKY130 → GDSII`

The implementation covered synthesis, floorplanning, placement, CTS, routing, and signoff.

The project received **3rd Place in the Poster Competition at the IEEE SAC Nordeste Brasil Awards 2026**.

### RISC-V / FPGA

I'm also exploring FPGA-based SoC development using LiteX as part of the development and study of a custom RISC-V processor.
